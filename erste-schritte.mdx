## In 5 Schritten zum ersten Agenten

Als Beispiel bauen wir einen **Empfangs-Agenten**, der Anrufer je nach Anliegen an das richtige Team weiterleitet.

<Steps>
  <Step title="Agenten anlegen">
    Legen Sie über den **Agenten-Assistenten** einen neuen Agenten an. Vergeben Sie einen Namen und hinterlegen Sie eine kurze **Begrüßung**, z. B. „Guten Tag, Sie sind mit dem Empfang verbunden. Wie kann ich helfen?"
  </Step>
  <Step title="Anliegen erkennen">
    Fügen Sie im **Flow-Editor** einen Gesprächs-Zustand hinzu, in dem der Agent das Built-In-Tool **`classify`** nutzt. Definieren Sie die möglichen Kategorien – z. B. `vertrieb`, `support`, `sonstiges`. Der Agent ordnet das Anliegen genau einer davon zu.
  </Step>
  <Step title="Weiterleiten">
    Verbinden Sie jede Kategorie mit einem Ziel: Legen Sie je einen **Weiterleiten**-Zustand mit der passenden **Rufnummer** an (Vertrieb, Support, Zentrale). Für unklare Fälle können Sie stattdessen nachfragen oder **auflegen**.
  </Step>
  <Step title="Test-Anruf">
    Prüfen Sie den Agenten mit einem **Test-Anruf direkt im Browser** – ohne echten Anruf. Sprechen Sie typische Anliegen ein und sehen Sie, ob korrekt eingeordnet und weitergeleitet wird. Details: [Agenten testen](/agenten-testen).
  </Step>
  <Step title="Veröffentlichen & Rufnummer zuweisen">
    Veröffentlichen Sie den Flow als **Version**, aktivieren Sie diese und weisen Sie dem Agenten eine **Rufnummer** zu. Ab dann nutzen neue Anrufe die aktive Version.
  </Step>
</Steps>
